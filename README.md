# Quick Note Studio - Progressive Web App

This is an installable PWA web application generated with PWA Studio.

## How to Install on Chromebook or Chrome:
1. Upload these files to a free host like Netlify Drop (https://app.netlify.com/drop) or GitHub Pages.
2. Open your live HTTPS link in Chrome on your Chromebook or Desktop.
3. Click the Install Icon in the top right of the address bar.
4. Enjoy your native-like standalone app!
